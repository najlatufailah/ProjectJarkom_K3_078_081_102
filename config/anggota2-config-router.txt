LANGKAH 0 - CEK DULU SEBELUM PASTE (penting)
1. Kabel antar-router di topologi = SERIAL (garis merah bergerigi), bukan Gigabit.
   Sheet Interface Anggota 1 masih menulis Gi0/x untuk link antar-router; di file ini
   semuanya diganti port Serial. Router 2911 hanya punya 3 port Gigabit, jadi link
   router-router memang harus serial.
2. Modul yang harus terpasang (matikan router dulu, drag HWIC-2T ke slot, nyalakan lagi):
   R-PUSAT: 3x HWIC-2T (5 serial) | R-UTARA: 1x (2 serial; +1x lagi saat L7 ditambah)
   R-DC: 1x | R-SELATAN: 1x | R-TIMUR: 1x | R-BARAT: 1x | R-PELABUHAN: 1x
3. Nama port di file ini ASUMSI (urutan slot). Cek yang sebenarnya di tiap router:
      show cdp neighbors          <- tampil port lokal -> perangkat tetangga & port-nya
      show ip interface brief
   Kalau beda (mis. link ke R-DC ternyata Serial0/1/0), ganti nama interface-nya saja
   di blok router itu (cari-ganti nama port, termasuk "tunnel source").
   Asumsi yang dipakai:
     R-PUSAT : Gi0/0=R-ISP, Gi0/1=SW-SRV-BALAIKOTA, Gi0/2=SW-PEGAWAI,
               Se0/0/0=R-DC, Se0/0/1=R-UTARA, Se0/1/0=R-SELATAN, Se0/1/1=R-TIMUR, Se0/2/0=R-BARAT
     cabang  : LAN pertama (WiFi/CCTV/SCADA) di Gi0/1, LAN kedua di Gi0/2, Gi0/0 kosong, Se0/0/0 = ke R-PUSAT
               (LAN dengan PC uji terkonfirmasi lewat ping; port WiFi (tanpa PC) hanya terkonfirmasi up/up.
                Pengecualian R-UTARA: Gi0/1 = Sensor, Gi0/2 = WiFi;
                R-PELABUHAN: Gi0/0 = SCADA, Gi0/1 = Kantor, Gi0/2 kosong)
     R-UTARA : Se0/0/0=R-PUSAT, Se0/0/1=R-PELABUHAN
     R-PELABUHAN: Se0/0/0=R-UTARA
4. clock rate ditulis di KEDUA ujung serial. Di ujung DTE router membalas
   "This command applies only to DCE interfaces" - abaikan, tidak berbahaya.
   Cek sisi DCE: show controllers serial0/0/0 (di R-PUSAT).
5. Urutan konfigurasi bebas, tapi tunnel baru up setelah R-PUSAT, R-UTARA, dan
   R-PELABUHAN selesai. Tiap blok mulai dari "enable" sampai "write memory".

DESAIN ROUTING (ringkas)
- Cabang (DC, SELATAN, TIMUR, BARAT): default route ke R-PUSAT.
- R-PUSAT: static route spesifik ke semua LAN cabang + default ke R-ISP (203.0.113.14).
- LAN Pelabuhan dari R-PUSAT lewat Tunnel0 (next-hop 192.168.3.2), sehingga traceroute
  pusat -> pelabuhan melewati tunnel. Paket GRE sendiri dibawa fisik via R-UTARA (L2 + L6).
- Tujuan tunnel (10.24.241.54 / 10.24.241.37) SENGAJA punya route /30 lewat jalur fisik
  supaya tidak rekursif (tunnel tidak boleh mencari tujuannya lewat tunnel sendiri).
- R-PELABUHAN: default ke R-UTARA (10.24.241.53), 10.24.0.0/16 via tunnel (192.168.3.1); LAN R-UTARA langsung via L6.
- NAT/PAT di R-PUSAT (outside = Gi0/0): ACL 1 = 10.24.0.0/16 + 192.168.3.0/30.
  (Packet Tracer tidak menerima "ip nat inside" di Tunnel0, maka internet dari pelabuhan keluar lewat R-UTARA, bukan tunnel.)

BAGIAN C - PENGUJIAN (isi kolom Hasil, lalu screenshot)
========================================================================
C1. Link langsung (dari router)
  R-PUSAT : ping 203.0.113.14 | ping 10.24.241.34 | .38 | .42 | .46 | .50
  R-UTARA : ping 10.24.241.54
C2. GRE tunnel
  R-PUSAT : show interface tunnel0   (harus up/up)  | ping 192.168.3.2
  R-PELABUHAN : show interface tunnel0 | ping 192.168.3.1
C3. Antar-lokasi (dari PC). Harapan: semua berhasil (Hasil: ... )
  PC-PEGAWAI      -> PC-CCTV-KOTA, PC-PUSKESMAS, PC-SENSOR-LALIN, PC-SENSOR-BANJIR, PC-PJU, PC-SCADA, PC-KANTOR-PEL
  PC-SCADA        -> PC-SENSOR-LALIN (langsung via L6), PC-CCTV-KOTA, PC-PJU
  PC-KANTOR-PEL   -> PC-PEGAWAI
  PC-CCTV-KOTA    -> PC-PUSKESMAS
C4. Traceroute (tracert di PC) - bukti tunnel dipakai
  PC-PEGAWAI -> PC-SCADA   : hop 10.24.224.1 -> 192.168.3.2 -> 10.24.160.10
  PC-CCTV-KOTA -> PC-SCADA : hop 10.24.96.1 -> 10.24.241.33 -> 192.168.3.2 -> 10.24.160.10
  PC-SENSOR-LALIN -> PC-SCADA (pembanding, TANPA tunnel): 10.24.236.1 -> 10.24.241.54 -> 10.24.160.10
C5. Internet (NAT)
  Semua PC : ping 8.8.8.8      (dari router: extended ping, lihat C6)
  R-PUSAT  : show ip nat translations | show ip nat statistics
C6. Tanpa PC (cadangan): extended ping dari router. Ketik "ping" saja lalu Enter, isi:
      Protocol [ip]: Enter | Target IP address: <tujuan> | Repeat/Datagram/Timeout: Enter
      Extended commands [n]: y | Source address or interface: <IP LAN router asal>
      sisanya Enter sampai selesai. Contoh di R-DC: tujuan 8.8.8.8, source 10.24.96.1

CATATAN KOORDINASI
- Anggota 1: link antar-router di sheet Interface perlu diubah dari Gi0/x ke Serial (lihat Langkah 0).
- Anggota 3 (OSPF): static route punya AD 1, OSPF AD 110, jadi route statis akan menang dan
  failover L7 tidak terlihat. Saat tahap OSPF, hapus static route antar-router (cabang & R-PUSAT ke LAN cabang)
  dan pertahankan default route ke ISP + NAT + GRE, atau ubah static jadi floating (AD 200).
- Anggota 3 (DHCP): ip helper-address dipasang di interface LAN router (mis. R-DC Gi0/0 untuk CCTV);
  tidak ada di file ini. Link L7 (R-DC .57 / R-UTARA .58) juga dari Anggota 3.
